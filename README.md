
Notes JWT API

RESTful API сервис для управления заметками с аутентификацией на основе JWT-токенов, написанный на языке Go. Проект организован по классической Clean Architecture (Стандартная структура Go-проектов с разделением на cmd/ и internal/). Включает поддержку миграций базы данных и контейнеризацию через Docker.

🛠️ Технологический стек

• Язык разработки: Go (Golang)
• Аутентификация: JWT (JSON Web Tokens) для безопасной авторизации запросов
• Драйвер БД: pgx (Toolkit and PostgreSQL driver for Go) — быстрый и производительный драйвер для работы с PostgreSQL.
• Миграции: Автоматический накат структуры БД (migrations/)
• Окружение: Контейнеризация через Docker Compose

📂 Структура проекта

• /cmd/api — Точка входа в приложение, инициализация подключения к PostgreSQL через pgx, пул соединений и запуск HTTP-сервера.
• /internal — Основная бизнес-логика (сервисы, pgx-репозитории для работы с БД, обработчики маршрутов, middleware для JWT).
• /migrations — SQL-скрипты для создания и обновления таблиц в базе данных.
• .env — Файл конфигурации переменных окружения (секреты JWT, порты, строка подключения к PG).
• docker-compose.yml — Файл для быстрой сборки и развертывания приложения и контейнера PostgreSQL.

Вариант 2: Локальный запуск

Если вы хотите запустить сервис напрямую на вашем компьютере:
1. Убедитесь, что у вас установлена Go и запущен локальный сервер PostgreSQL.

   Перед запуском создайте файл .env в корневой директории и укажите параметры подключения. Вы можете использовать как отдельные переменные, так и полную строку подключения DATABASE_URL для pgx:
```env
SERVER_PORT=8080

Секретный ключ для подписи токенов

Настройки подключения для pgx (пример)

DATABASE_URL=postgres://postgres:secret@localhost:5432/notes_db?sslmode=disable
```

🔑 Основные Эндпоинты (API)


Аутентификация

• POST /api/auth/register — Регистрация нового пользователя.
• POST /api/auth/login — Авторизация (возвращает JWT-токен в ответе).

Заметки (Доступны только с валидным JWT-токеном в заголовке Authorization: Bearer <token>)

• GET /api/notes — Получить список всех заметок текущего пользователя.
• GET /api/notes/:id — Получить конкретную заметку по ID.
• POST /api/notes — Создать новую заметку.
• PUT /api/notes/:id — Редактировать существующую заметку.
• DELETE /api/notes/:id — Удалить заметку.
